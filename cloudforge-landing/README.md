# CloudForge landing page

A responsive CloudForge landing page with a generated mountain hero wallpaper.

## Run locally

From the repository root:

```sh
pnpm install
pnpm run dev
```

Then open http://localhost:3000. To run this app from its directory instead,
use `pnpm dev`.

The page imports its own stylesheet; no Tailwind or icon dependency is required.

## Before deploying

- Replace the `https://github.com/` link with your repository.
- Replace the demo modal with an embedded demo or URL.
- The uptime and API status are visual placeholders. Connect these to a real endpoint before claiming live monitoring.
- Replace the April 2025 last-checked value with real health-check data.
- Architecture visuals are custom SVG/CSS approximations, not AWS-provided icons.
